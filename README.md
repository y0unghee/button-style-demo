# 버튼 스타일 데모

웹빌더 서비스의 **버튼 스타일 편집** 화면 데모입니다. 오른쪽 패널에서 버튼의 디자인과 크기를 바꾸면 데스크탑·모바일 미리보기에 바로 반영됩니다.

## 기능

- **디자인**: 강조 / 보조 / 테두리 / 연한 테두리 / 텍스트 버튼
- **크기**: 크게 / 보통 / 작게 / 사용자 지정
  - 사용자 지정: 데스크탑·모바일 각각 좌우(0–5em)·상하(0–5em) 패딩 입력, 슬라이더 조절
  - 모바일 좌우 패딩은 '너비 채우기' 지원
  - 텍스트 버튼은 패딩이 없어 사용자 지정 미제공

## 실행 방법

```bash
npm install
npm run dev
```

React + TypeScript + Vite + Tailwind CSS
